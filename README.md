# Airdrop Eligibility Checker 2025

**Manifest V3 Chrome Extension** - Detects real 2025-2026 airdrop eligibility

## Features
- ✅ 10 live airdrop APIs (Monad, LayerZero, Eclipse, Base, etc.)
- ✅ Official claim pages only - no fake buttons
- ✅ Clean MV3 architecture
- ✅ Open source - no drainers

## Install
1. Download ZIP from GitHub
2. Extract to folder
3. Chrome → Extensions → Load Unpacked → Select folder
4. Enter wallet address (0x...) → Check Eligibility

## APIs Checked
- Monad (MON)
- LayerZero V2
- Eclipse SVM
- Base Network
- Metamask Snaps
- Arbitrum Season 2
- Optimism Retro
- Wormhole
- Meteora (Solana)
- OpenSea SEA

## Security
- Read-only checks
- No transaction signing
- No private keys stored
- Open source code
